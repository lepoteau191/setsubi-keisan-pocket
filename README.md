# 設備計算ポケット

現場・打ち合わせ中に必要な設備計算をすぐ確認するための、静的出力対応Next.jsアプリです。

## 搭載機能

- 空気線図・空気状態計算（乾球温度、相対湿度、絶対湿度、露点、湿球、エンタルピー）
- 露点・結露判定
- 絶対湿度計算
- 設備系単位換算（圧力、流量、熱量、温度）
- 風量・換気回数計算
- CO₂基準必要換気量（定常状態の物質収支による概算）
- ガラリ必要開口寸法
- 等摩擦法ダクトサイズ計算
- 水量・温度差・熱量計算
- ダクトサイズ・直管圧損概算
- 配管サイズ・直管圧力損失概算
- 給水器具負荷単位集計（地域プロファイル付き）
- 屋根雨水排水量計算（地域別の計画降雨強度プロファイル付き）
- グリーストラップ選定（利用人数法・必要流入流量と阻集質量・候補製品の性能照合）
- ポンプ揚程・動力概算
- 現場測定メモ・結露説明シート（端末内保存、コピー、印刷／PDF化）

## デプロイ

`next.config.ts` は `output: "export"` のため、`npm run build` の出力先 `out/` をそのまま静的ホスティングできます。

- Vercel: リポジトリを接続して通常どおりデプロイ
- GitHub Pages: ビルド時に `NEXT_PUBLIC_BASE_PATH=/リポジトリ名` を指定し、`out/` をPagesへ公開

計算ロジックは `src/lib/psychrometrics.ts`、`src/lib/equipment-calculations.ts`、`src/lib/regional-standards.ts` に分離しています。カードと将来追加ツールの定義は `src/lib/tool-registry.ts` にあります。

## 地域基準を使う計算について

水道・雨水関連は、自治体・排水先・建物用途・改定時期で基準が変わります。そのため地域プロファイルを選べるほか、案件ごとの地域名、降雨強度、流出係数を画面で直接上書きできます。

- 雨水：東京都23区、横浜市、愛知県（名古屋市）、三重県（北勢・桑名区分）、静岡県（静岡市）、岐阜県（岐阜市）、石川県（金沢市）、富山県（富山市）、福井県（福井市）、長野県（長野市）、独自指定を収録
- 岐阜市・富山市・長野市は公開された降雨強度式を登録し、継続時間を変えると降雨強度を再計算
- 給水器具負荷単位：横浜市の公開表（国土交通省設計基準・SHASE-S 206引用）を標準テーブルとして集計し、対象地域を記録・確認できる構成

最終的な設計・申請・施工判断では、必ず所管自治体・水道事業体の最新資料、協議条件、仕様書を優先してください。

## グリーストラップ選定

`src/lib/grease-trap.ts` に計算を分離。中部コーポレーション2026年カタログp.273（SHASE-S217-2016引用）の利用人数法を採用し、洋食店の例を初期値にしています。2025年版の適合判定には未対応です。原単位・厨房使用時間・清掃周期は変更できます。候補製品は許容流入流量と標準阻集グリース質量の両方で照合し、判定には丸め前の値を使用します。必要性能の表示は小数第1位へ切り上げます。
